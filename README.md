# Metastaz Player

Tek dosyalık, sunucusuz video oynatıcı. Tarayıcının kendi `<video>` oynatıcısını kullanır (mp4, webm).

## Kullanım
1. `index.html` dosyasını indirip tarayıcıda aç (ya da GitHub Pages ile yayınla).
2. **Dosya aç**: bilgisayarındaki videoyu oynatır, hiçbir yere yüklenmez.
3. **Adres ekle**: doğrudan bir mp4/webm adresi yapıştır, başlık ver, **Listeye ekle**.
4. Liste ve kaldığın saniye yalnız bu tarayıcıda (localStorage) saklanır.

## Kısayollar
Boşluk oynat/duraklat · ← → 10 sn · N sonraki · F tam ekran · Xbox kolu: A, LB, RB.

## Not
Oynatıcı içerik barındırmaz ve içerik bağlantısı içermez. Yalnız hakkına sahip olduğun ya da açık lisanslı içerikleri oynat.
